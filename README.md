CCA Web App - Piattaforma Gestionale Accademica

Questa repository contiene il codice sorgente della CCA Web App, una soluzione Full-Stack sviluppata per la digitalizzazione dei flussi operativi del Collegio Carlo Alberto.

🚀 Panoramica del Progetto

L'applicazione nasce per centralizzare il monitoraggio della carriera studentesca, la gestione della didattica e il supporto amministrativo in un unico hub digitale.

🛠️ Stack Tecnologico

Runtime: Google Apps Script (V8 Engine)

Backend: JavaScript (Serverless Architecture)

Frontend: HTML5, CSS3 (Material Design), JavaScript (Single Page Application)

Database: NoSQL Simulation-Based Storage (PropertiesService)

Integrazioni: Google Classroom API, Gmail Service, Google Drive API

📋 Funzionalità Principali

Dashboard KPI: Calcolo in tempo reale della media ponderata e monitoraggio CFU.

Hub Didattico: Integrazione dinamica con Google Classroom per l'accesso rapido ai corsi.

Smart Ticketing: Sistema di instradamento automatico delle richieste verso la segreteria tramite Gmail API.

Gestione Notifiche: Motore ibrido per avvisi globali (Push/In-App) e comunicazioni broadcast.

🏛️ Architettura

Il progetto segue il pattern MVC (Model-View-Controller) per garantire la separazione delle responsabilità tra la logica di business (backend) e l'interfaccia utente (frontend).

Progetto sviluppato da Marco Mammoliti come parte della Tesi Magistrale in ICT e Media (Università di Torino).
